# Organize Your Windows

A collection of independent, safety-focused tools for organizing, migrating, and maintaining Windows data.

Each tool lives in its own top-level directory and includes its own setup, safety, and validation documentation.

## Projects

| Project | Purpose |
| --- | --- |
| [Folder Organizer](./folder-organizer/) | Review-first folder organization, duplicate detection, document classification, local indexing, and rollback. |
| [Windows Cache Mover](./windows-cache-mover/) | Audit, relocate, verify, and restore supported Windows application caches with NTFS junctions. |
| [Codex Mover](./codex-mover/) | Live-session-safe migration of Windows Codex state, runtime caches, local data, and the MSIX package. |

The projects are independent. Follow the safety checks and validation workflow in each project README before applying changes.
